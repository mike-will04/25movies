# 🎬 25movies

> Este repositório contém o projeto de um site de cinema desenvolvido em WordPress. O site exibe informações detalhadas sobre diferentes gêneros cinematográficos e lista filmes associados a cada gênero.

## 🚀 Tecnologias Utilizadas

- WordPress
- HTML
- CSS
- Bootstrap

## 📖 Funcionalidades

- ✅ **Informações sobre Gêneros do Cinema** – Exibe detalhes e características de diferentes gêneros cinematográficos.
- ✅ **Listagem de Filmes** – Apresenta filmes relevantes de acordo com o gênero selecionado.
- ✅ **Design Responsivo** – Layout otimizado para dispositivos móveis e desktops.
